## Image Guidelines

- Use high-quality, professional images
- Maintain consistent aspect ratios within each category
- Optimize images for web (compress without losing quality)
- Use descriptive file names that match the ones mentioned above
- For best results, use PNG format for UI screenshots and JPG for photos
