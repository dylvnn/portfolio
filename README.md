# Dylan Nguyen - Personal Portfolio Website

This is my personal portfolio website showcasing my skills, projects, and professional experience as a Software Engineer.

## Project Overview

This portfolio website was built using HTML, CSS, and JavaScript to create a responsive, modern dark-mode portfolio website inspired by contemporary minimalist design trends. The clean, dark aesthetic emphasizes content while providing a professional and sleek presentation of my work and skills.

## Features

- **Dark Mode Design**: Modern dark color scheme with accent highlights for improved readability and visual appeal
- **Fully Responsive**: Adapts seamlessly to all device sizes (mobile, tablet, desktop)
- **Animated Elements**: Subtle animations enhance user experience without overwhelming the interface
- **Interactive Projects Section**: Detailed project cards with smooth hover effects
- **Skills Categorization**: Visual organization of technical skills by category
- **Functional Contact Form**: Client-side form validation for user feedback
- **Social Media Integration**: Links to professional profiles and networks
- **Optimized Performance**: Fast-loading and accessible design principles

## Pages

1. **Home**: Interactive hero section with a brief introduction
2. **About**: Detailed background, skills, experience, and downloadable resume
3. **Projects**: Showcase of major development projects with visual cards
4. **Skills**: Categorized technical and professional abilities
5. **Contact**: Functional form and contact information
6. **Project Details**: Individual pages with comprehensive information for each project

## Technologies Used

- **HTML5**: Semantic markup for content structure
- **CSS3**: Modern styling with Grid and Flexbox for responsive layouts
- **JavaScript**: Interactive elements, animations, and form validation
- **Font Awesome**: Icon library for enhanced visual elements
- **Google Fonts**: Typography using Inter for consistent cross-platform display

## Design Inspiration

The design is inspired by modern developer portfolios with a focus on:
- Minimalist dark mode aesthetics
- Focus on content and typography
- Clean, spacious layouts with visual breathing room
- Interactive elements that enhance usability
- Professional presentation without unnecessary clutter

## How to Run Locally

1. Clone this repository:
   ```
   git clone https://github.com/dylvnn/portfolio.git
   ```

2. Navigate to the project directory:
   ```
   cd portfolio
   ```

3. Open index.html in your browser:
   - Double-click the file in your file explorer
   - Or use a local development server:
     ```
     # If you have Python installed:
     python -m http.server
     ```
     Then open `http://localhost:8000` in your browser
